# CLI Productivity Toolkit

A set of small, practical command-line utilities for everyday developer work.

## Tools included

- `organize.py` — Sort files into folders by extension
- `password_check.py` — Check password strength
- `json_format.py` — Pretty-print and validate JSON
- `gitignore_gen.py` — Generate common .gitignore files

## Installation

```bash
git clone https://github.com/johnny-glitch12/cli-productivity-toolkit.git
cd cli-productivity-toolkit
# No dependencies required for basic tools (Python 3.8+)
```

## Usage examples

```bash
python organize.py /path/to/folder
python password_check.py "MyP@ssw0rd"
python json_format.py data.json
python gitignore_gen.py python
```
